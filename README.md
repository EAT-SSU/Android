## 🛠 Tech Stack
- Kotlin
- MVVM
- Clean Architecture
- Coroutine + Flow
- UiState
- Hilt
- xml + viewBinding (+dataBinding)
- Retrofit2 + Okhttp3
- Gilde
- KaKao OAuth SDK
- Firebase RemoteConfig, Crashlytics
