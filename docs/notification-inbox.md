# 알림 발송 및 알림함

## 매일 11시 로컬 알림

- 기존 AlarmManager 평일 알림 정책을 유지한다. 토·일요일에는 발송하지 않는다.
- AlarmManager 수신 시 WorkManager에서 서버의 메뉴찜 목록과 오늘 점심·저녁 식단을 비교한다.
- 비교 대상은 학생·도담·기숙사·교직원 식당이다. 각 식당의 미운영 시간대는 조회하지 않는다.
- 시간대별로 일치한 메뉴가 있으면 해당 시간대에 한 건씩 발송한다. 점심·저녁 모두 일치하면 두 건이다.
- 메뉴가 없거나 조회에 실패해 일치 항목을 확인하지 못하면 기존 고정 문구 한 건을 발송한다.
- 같은 식당·메뉴 ID가 여러 식단 항목에 반복되어도 한 번만 센다.
- 1개: `🍽️ 찜한 메뉴가 나온대요!` / `오늘 점심, 학생식당에 파스타 등장 👀`
- 2개: `🍽️ 찜한 메뉴가 2개나 나온대요!` / `오늘 점심, 학생식당 파스타 · 도담식당 파스타 등장 👀`
- 3개 이상: `🍽️ 찜한 메뉴가 여러 개 나온대요!` / `오늘 점심, 학생식당 파스타 외 2개 등장 👀`
- 저녁의 경우 위 본문의 `점심`이 `저녁`으로 바뀐다.
- 재부팅·앱 업데이트·기기 시간/시간대 변경 시 알림 허용 상태를 확인해 다시 예약한다.
- 알림 설정 해제/로그아웃 후 대기 작업은 발송하지 않는다. 날짜가 지난 작업도 발송하지 않는다.

## 저장과 읽음

로컬·수신 가능한 FCM 모두 NotificationPublisher → NotificationStore의 같은 경로를 사용한다.
알림 ID로 중복 저장/표시를 막고, 중복 메시지로 기존 읽음 상태를 미읽음으로 되돌리지 않는다.
서버 알림 조회 API가 없으므로 **알림함 내역만** DataStore에 기기별로 보관한다.
메뉴찜 목록 자체는 기존 서버 API에서 조회·등록·삭제한다.

최근 7 × 24시간 내역을 보여주며 저장/화면 진입 시 만료 항목을 정리한다.
알림함과 학식 탭의 미읽음 아이콘은 동일한 저장소를 관찰한다.
개별 클릭과 ‘모두 읽음’은 로컬·FCM 항목에 동일하게 적용된다.

## 클릭 시 이동

- 일반 고정 문구 / 날짜·시간 정보가 없는 일반 FCM: 기본 학식 탭.
- 찜 맞춤 알림: 알림의 날짜와 점심/저녁을 선택하고, 식당 목록이 로드된 뒤 해당 식당 제목으로 스크롤.
- 여러 식당이 해당하면 화면의 식당 정렬 순서 (학생 → 도담 → 기숙사 → 교직원)에서 가장 앞 식당을 선택한다.
- 시스템 알림 클릭과 알림함 항목 클릭이 같은 목적지 정보를 전달한다.
- 상세 화면이나 바텀시트는 열지 않는다.

## Firebase Console 발송 범위

콘솔의 Notifications Composer 발송을 유지한다.

- 앱 전경: FirebaseMessagingService에서 받은 제목·본문을 알림함에 저장하고 시스템 알림도 표시한다. 식단 메타데이터가 없어도 저장한다.
- 백그라운드/종료: Android가 직접 표시하는 `notification` 메시지는 앱 콜백을 거치지 않으므로 수신 시점에 알림함으로 수집할 수 없다.
- 콘솔 ‘맞춤 데이터’에 `title`, `body`를 함께 넣은 메시지는 사용자가 시스템 알림을 누를 때 해당 데이터로 내역을 수집할 수 있다. 이 경우 이미 클릭했으므로 읽음
  처리한다.
- 백그라운드에서 누르지 않은 알림까지 모두 보관하려면 향후 서버 내역 조회 API 또는 data 메시지 발송이 필요하다. 이번 작업에는 서버 발송 변경이 포함되지 않는다.

콘솔 맞춤 데이터 또는 FCM data에서 지원하는 선택적 이동 필드:

```json
{
  "title": "🍽️ 찜한 메뉴가 나온대요!",
  "body": "오늘 저녁, 기숙사식당에 파스타 등장 👀",
  "meal_date": "2026-11-02",
  "meal_time": "dinner",
  "restaurants": "DORMITORY,DODAM"
}
```

`meal_date`는 ISO 날짜, `meal_time`은 `breakfast`/`lunch`/`dinner`이다.
`restaurant` 단일 값도 지원하며, 여러 식당은 `restaurants`에 쉼표로 구분한다.
유효한 날짜·시간이 없으면 특정 날짜를 추측하지 않고 기본 학식 화면으로 연다.

공식 수신 동작: https://firebase.google.com/docs/cloud-messaging/android/receive-messages
